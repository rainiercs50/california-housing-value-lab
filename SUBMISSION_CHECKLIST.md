# Midterm Submission Checklist

## Included in this package

- [x] Streamlit app (`app.py`)
- [x] Requirements file (`requirements.txt`)
- [x] Dataset file (`california_housing_midterm.csv`)
- [x] Dataset has 500+ rows
- [x] Dataset has 8+ variables
- [x] Dataset has numerical variables
- [x] Dataset has categorical variables
- [x] Continuous target variable
- [x] Introduction / exploration page
- [x] Data visualization page
- [x] Prediction / model page
- [x] Linear Regression model
- [x] R², MAE, and RMSE metrics
- [x] Actual vs predicted chart
- [x] Prediction simulator
- [x] Separate presentation notes file

## Before submitting

1. Push the project to GitHub.
2. Deploy it on Streamlit Community Cloud.
3. Open the deployed app link and confirm all pages load.
4. Submit the deployed Streamlit link.
5. Practice using the separate `presentation_notes.md` file, not inside the app.
